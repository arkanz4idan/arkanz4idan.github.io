cos% is a Linux distribution currently in early development. Install with a single command. No package, no GUI — just a shell script.

// install

For regular users. Pick your architecture and run the command.

x86_64

Standard 64-bit PCs & laptops

curl
$ bash <(curl -s https://arkanz4idan.github.io/cospersent/x86_64/install.sh)

or use wget

wget
$ bash <(wget -qO- https://arkanz4idan.github.io/cospersent/x86_64/install.sh)
ARM

ARM-based boards & devices

curl
$ bash <(curl -s https://arkanz4idan.github.io/cospersent/ARM/install.sh)

or use wget

wget
$ bash <(wget -qO- https://arkanz4idan.github.io/cospersent/ARM/install.sh)
Raspberry Pi

RPi 3, 4 & compatible — flashes directly

curl
$ bash <(curl -s https://arkanz4idan.github.io/cospersent/raspberrypi/flash.sh)

or use wget

wget
$ bash <(wget -qO- https://arkanz4idan.github.io/cospersent/raspberrypi/flash.sh)

// build your own

For developers. Use cos% as a base to build your own custom distro.

x86_64 base

Build a custom distro for standard 64-bit

curl
$ bash <(curl -s https://arkanz4idan.github.io/cospersent/build.sh)
ARM base

Build a custom distro for ARM devices

curl
$ bash <(curl -s https://arkanz4idan.github.io/cospersent/build-arm.sh)
